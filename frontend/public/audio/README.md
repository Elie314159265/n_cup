# 事前録音音声ファイル

AR会話デモ用の音声ファイルをここに配置してください。

## ファイル命名規則

```
response_0.mp3
response_1.mp3
response_2.mp3
response_3.mp3
response_4.mp3
```

## 動作フロー

1. ユーザーがマイクボタンを**押し続ける** → 録音中
2. ボタンを**離す** → 録音停止
3. 次のインデックスの `response_N.mp3` が自動再生
4. 再生中は波形アニメーションが表示される
5. 再生終了 → 次のインデックスに進む（5個でループ）

## 音声ファイルの準備例

- AIの返答をあらかじめ Amazon Polly / ElevenLabs などで生成して mp3 として保存
- 会話の流れに沿った順番で `response_0.mp3` 〜 `response_4.mp3` に名前を変更

## フォーマット

| 項目           | 推奨値        |
| -------------- | ------------- |
| フォーマット   | MP3           |
| サンプルレート | 22050 Hz 以上 |
| ビットレート   | 128 kbps      |
